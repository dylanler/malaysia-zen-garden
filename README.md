# malaysia-zen-garden

A slow, walkable, sound-led Three.js zen garden built from Malaysian millennial memory, representing Malay, Chinese, Indian, Kadazan-Dusun and Iban cultures with equal weight.

Start with [PLAN.md](./PLAN.md): concept, station-by-station design, sound and art direction, controls for desktop and mobile, technical architecture, milestones and open decisions.
